Curated List of SaaS Products & Open-Source GitHub Projects
Focused on Asset Reliability, Predictive Maintenance, Industrial AI & Asset Lifecycle Optimization
Last updated: September 2026

This repository tracks notable SaaS/hosted platforms and open-source projects for Enterprise Asset Performance Management (APM). These tools monitor asset health, detect anomalies, predict failures, optimize maintenance strategies, improve reliability, and use operational and sensor data to increase asset availability and lifecycle performance. IBM describes APM as combining asset-health monitoring, reliability engineering, predictive analytics, and maintenance decision support.

Examples include GE Digital APM, IBM Maximo APM, Bentley AssetWise, Siemens Senseye Predictive Maintenance, AVEVA APM, Hexagon APM, Hitachi Lumada APM, Aspen Mtell, IFS APM, and Oracle APM.

Open-source emphasis: This section is heavily expanded with open-source IoT platforms, industrial time-series databases, predictive-maintenance frameworks, digital-twin platforms, condition-monitoring tools, observability systems, workflow engines, and machine-learning infrastructure that can be combined to build self-hosted APM solutions. For example, ThingsBoard provides open-source asset/device management, telemetry collection, alarms, dashboards, and rule processing, while Apache IoTDB is specifically designed for industrial IoT time-series data and integrates with tools such as Grafana and ThingsBoard.

Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

Open-Source GitHub Projects

ThingsBoard
Open-source IoT platform providing device and asset management, telemetry collection, rule processing, alarms, dashboards, and real-time monitoring. It can serve as a strong foundation for custom APM systems.

Apache IoTDB
Open-source industrial IoT time-series database designed for high-volume sensor data, time-series analytics, device hierarchies, and edge-cloud deployments.

Grafana
Open-source visualization and observability platform suitable for asset-health dashboards, condition monitoring, sensor telemetry, maintenance KPIs, and reliability analytics.

Prometheus
Open-source monitoring and time-series platform useful for collecting equipment and infrastructure metrics, defining alert rules, and feeding asset-health dashboards.

InfluxDB
Open-source time-series database useful for storing high-frequency industrial sensor, machine-health, energy, and equipment telemetry.

OpenTelemetry Collector
Open-source telemetry collection and processing framework that can be adapted to ingest operational measurements from distributed industrial systems.

Node-RED
Open-source flow-based programming platform for connecting industrial sensors, PLCs, APIs, databases, alerts, and maintenance workflows.

Eclipse IoT Projects
Open-source industrial IoT ecosystem containing frameworks and protocols for device connectivity, messaging, digital twins, edge computing, and telemetry.

Eclipse Ditto
Open-source digital-twin framework for representing connected physical assets, synchronizing their state, and integrating telemetry with enterprise applications.

Eclipse Kura
Open-source IoT edge framework for deploying applications and managing connectivity on industrial gateway devices.

Eclipse Milo
Open-source implementation of OPC UA functionality useful for connecting industrial equipment and control systems to asset-performance platforms.

Open62541
Open-source OPC UA implementation useful for collecting standardized industrial equipment and process data from PLCs and automation systems.

FIWARE
Open-source smart-industry and IoT ecosystem providing context-management components useful for connecting assets, sensors, telemetry, digital twins, and analytics.

Open-source context broker for managing real-time context information about assets, devices, sensors, locations, and industrial environments.

ThingsBoard Gateway
Open-source IoT gateway for connecting legacy and industrial protocols such as Modbus, CAN, BACnet, BLE, OPC-UA, MQTT, ODBC, and REST to an IoT platform.

Apache Kafka
Open-source event-streaming platform suitable for transporting high-volume equipment telemetry and industrial events between edge systems, databases, analytics engines, and APM applications.

Apache Flink
Open-source stream-processing framework suitable for real-time anomaly detection, event processing, feature generation, and sensor-data analytics.

Apache Spark
Open-source distributed analytics engine useful for large-scale historical asset-data analysis, machine-learning pipelines, and predictive-maintenance workloads.

Apache Airflow
Open-source workflow orchestration platform for scheduling predictive-maintenance pipelines, model retraining, asset-data processing, and reliability reports.

Apache NiFi
Open-source dataflow platform for ingesting, transforming, routing, and synchronizing equipment and operational data from heterogeneous industrial systems.

OpenSearch
Open-source search and analytics engine suitable for equipment events, alarms, maintenance records, failure logs, inspection reports, and operational data.

MLflow

TensorFlow

Disclaimer
